CYBERSECURITY: STAY ALERT

A game should not need remote control of your computer.

The previous downloadable build combined a Snake game launcher with a remote-access client. The source indicates that the client can connect to a remote host, run commands, collect system information, transfer files, capture a screenshot, and create a Windows Startup entry. These features can expose your device and data; do not run that build.

Check before you download

Verify the publisher and source through a separate trusted channel. Be cautious of unexpected files, urgent prompts, and programs asking for access unrelated to their purpose.

Look beyond appearances

A program can look like a game yet start unrelated code in the background. A familiar filename, icon, or website does not prove what it does; check its source and requested permissions.

Keep this sample offline

Do not run the previously distributed build. Any necessary analysis belongs in a disposable, isolated lab with no network access, shared folders, or personal data.
